# Clean-room checklist

This project is written from the Histeries specifications and public documentation restated in the maintainer's own words.

- [ ] Every behavioral rule has a provenance tag: `observed`, `public-doc`, or `designed`.
- [ ] No decompiled or disassembled code was requested, read, summarized, or used.
- [ ] No commercial game's shipped data, scripts, proprietary text, art, audio, UI, or iconography was used.
- [ ] No third-party mod code, data, or text was used.
- [ ] Missing or ambiguous behavior is proposed as a `designed` rule and recorded in an ADR.
- [ ] Dependencies use an MIT, Apache-2.0, BSD, ISC, Zlib, or Unicode-compatible license.
- [ ] Every asset has a provenance line in `assets/LICENSES.md`.
- [ ] Code and content are original and use the Histeries names and interfaces.

Reviewers should stop the task when forbidden material appears and request a behavioral description from the maintainer.
