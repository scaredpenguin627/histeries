# Phase 5 — Geodesic topology

P5-02 adds the closed spherical graph and its surface geometry in `histeries-hex`. The implementation uses integer coordinates and stable tile IDs. The topology suite checks shared edges, independent reconstruction and routing against a separate breadth-first search. Codex authored the changes. Each independent review uses a fresh Sol 6.2 subagent at maximum reasoning effort. The bookmark is `task/phase5-geodesic-topology`. [Specification](../../specs/geodesic.md) · [ADR-0024](../adr/0024-geodesic-topology.md)

All ordered pairs on the 12-, 42- and 92-cell boards and 1,156 sampled pairs on the 642-cell board agreed with the reference search on Windows GNU. The largest mesh test counted 12 five-sided and 10,230 six-sided cells. The first independent review identified that two constructions could agree even if both had changed their numbering. Fixed fingerprints now cover all centers, directed neighbor slots and corners at frequencies 1, 2 and 3. To reproduce the five black-box tests and the route and mesh measurements, run `cargo test --locked -p histeries-hex --test geodesic -- --nocapture --test-threads=1`. GitHub Actions repeats the measurement on every native PR runner. [Scorecard](../scorecard.md)
